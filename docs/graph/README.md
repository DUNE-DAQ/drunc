# Graph

These are interactive UML diagrams generated from the `drunc` source code with
[`daqpytools-generate-uml`](https://github.com/DUNE-DAQ/daqpytools). Boxes are
colored by their top-level source directory (see the legend), and clicking a
box links to its definition on GitHub.

**Interacting with a diagram:** drag to pan, scroll to zoom (or use the
+/-/Reset buttons), and use the search box to jump straight to a class or
module. The legend stays fixed on screen while you pan and zoom.

Note that diagrams generated in the source directory will only refer to those in said
directory! No links into or out of the directory will be captured in these folders.
For the full map, you will have to refer to the overall graphs.
